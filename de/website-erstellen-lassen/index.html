ENTSCHEIDUNG / 02

Nicht möglichst viele Seiten. Sondern die richtigen.

Eine Seite ist begründet, wenn sie eine eigenständige Leistung, Frage, Zielgruppe oder Entscheidung beantwortet. Deshalb entsteht der Umfang aus Angebot und Nachfrage — nicht aus einem vorgefertigten Paket mit einer beliebigen Seitenzahl.

FRAGEN / 08

Vor der Beauftragung.

Was kostet es, eine professionelle Website erstellen zu lassen?+

Eine fokussierte Website mit 5–7 gewichteten Seiten beginnt bei 3.500 € für die Entwicklung. Ein vollständiger Start mit Nachfrageanalyse, SEO-Grundlage, Analytics und erster Werbeeinrichtung beginnt bei 5.500 €. Der konkrete Umfang hängt von Seitentypen, Inhalt, Funktionen, Integrationen und Migration ab.

Kann nur die Website-Entwicklung beauftragt werden?+

Ja. Reine Entwicklung und vollständiger Start sind getrennte Produkte. Bereits vorhandene Analyse, SEO-Planung oder Analytics werden nicht noch einmal berechnet.

Was bedeutet eine gewichtete Seite?+

Eine Startseite, eine eigenständige Leistungsseite und eine wiederkehrende Rechteseite verursachen nicht denselben Aufwand. Der Umfang wird deshalb nach Seitentyp, Inhalt und Funktion bewertet und nicht nur nach der Zahl der URLs.

Ist SEO bereits in der Website enthalten?+

Die Entwicklung umfasst eine technisch indexierbare Website. Beim vollständigen Start kommen Nachfrageanalyse, Suchstruktur, Metadaten, interne Verlinkung und weitere SEO-Grundlagen hinzu. Laufende SEO-Arbeit nach Veröffentlichung ist eine separate Leistung.

Welche Technik oder welches CMS wird verwendet?+

Die technische Basis wird nach Inhalt, Redaktion, Geschwindigkeit, Funktionen und Wartungsbedarf gewählt. Die Website und vereinbarten Zugänge werden an den Auftraggeber übergeben; eine dauerhafte Bindung an Manul ist nicht erforderlich.

In welcher Sprache läuft das Projekt?+

Die Projektleitung kommuniziert auf Englisch. Deutsche Inhalte können strukturiert, gestaltet und technisch umgesetzt werden. Übersetzung, Fotografie und rechtliche Prüfung werden bei Bedarf separat vereinbart.
