QUESTIONS BEFORE STARTING / 08

Before we start.

Does Manul work with businesses throughout Ireland?+

Yes. Projects are delivered remotely across the Republic of Ireland. The scope, review dates, calls and people responsible for approval are agreed before production starts.

Can we order website development without the complete launch?+

Yes. Development-only is available when the research, search plan, analytics and acquisition setup already exist and are usable. We do not add the same work twice.

Are the prices shown in euro?+

Yes. Starting prices on this page are in euro. The written estimate depends on page types, content, functionality, integrations, migration and the launch services selected.

Can the website target one town, several counties or all of Ireland?+

Yes, but those are different search and content structures. We define which services need a local page, which locations need their own useful information and which pages should remain national before development begins.

How are cookies, forms and analytics handled?+

We map what each form collects, where data is sent and which analytics or advertising tools are required. Non-essential tracking is connected to the agreed consent controls. Final legal wording and compliance decisions remain with the client and their Irish adviser.

How does website redesign pricing work?+

A visual update may add 0–10%. Preserving content, URLs and search value normally adds 10–20%; complex CMS, form or integration migration may add 20–35%. A difficult legacy system is diagnosed and estimated separately.

Will Manul maintain a website built by another studio?+

Ongoing support is available for websites built by Manul. An existing third-party website can be diagnosed and redesigned, but it is not taken into routine monthly support unchanged.
